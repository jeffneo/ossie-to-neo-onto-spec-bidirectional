
  Constraints and indexes
Constraints are listed under the constraints of a node or relationship, and indexes under the indexes of its
extensions, each keyed by id.
nodes:
  movie:
    label: Movie
    properties:
      title:
        type: STRING
      released:
        type: INTEGER
    constraints:
      movie-title-unique:
        type: UNIQUE
        properties: [title]
    extensions:
      indexes:
        movie-released:
          type: RANGE
          labels: [Movie]
          properties: [released]

Constraint type
 | 
 | Type
 | Requires that
 | EXISTS
 | Every node or relationship has the property.
 | UNIQUE
 | No two nodes or relationships have the same values for the properties.
 | KEY
 | Every node or relationship has the properties, and no two have the same values for them.
 | PROPERTY_TYPE
 | The property’s values have the property’s type.

Index type
The type of an index.
FULLTEXT, POINT, RANGE, TEXT, VECTOR, LOOKUP
Index options
Configuration specific to the type of an index.
One of full-text options, point options, vector options,
chosen by its type.
