
  Nodes
A node describes a kind of entity in the domain. Nodes are listed under nodes, keyed by node id.
nodes:
  person:
    label: Person
    description: A person who acts in or directs movies.
    aliases: [Actor, Director]
    properties:
      name:
        type: STRING
        must_exist: true

Labels
The labels of a node.
 | 
 | Field
 | Type
 | Required
 | Description
 | identifier
 | string
 | No
 | The label which identifies the node.
 | implied
 | list of strings
 | No
 | Labels implied by the node in addition to the identifier.
 | optional
 | list of strings
 | No
 | Labels which may be present on the node but aren’t required.
 | extensions
 | custom data
 | No
 | Extensions for the labels.
