
  Relationships
A relationship describes how entities in the domain relate. Relationships are listed under relationships, keyed by
relationship id.
relationships:
  acted-in:
    type: ACTED_IN
    description: The person appeared in the movie as a cast member.
    from:
      node: person
    to:
      node: movie
      min_count: 1
    properties:
      role:
        type: STRING

Relationship end
One end of a relationship.
 | 
 | Field
 | Type
 | Required
 | Description
 | node
 | string
 | No
 | Id of the node at this end.
 | label
 | string
 | No
 | Label of the node at this end.
 | count
 | integer
 | No
 | Exact number of relationships per node at this end. Null when unconstrained.
 | min_count
 | integer
 | No
 | Minimum number of relationships per node at this end.
 | max_count
 | integer
 | No
 | Maximum number of relationships per node at this end.
A relationship end sets either count, or min_count and max_count.
